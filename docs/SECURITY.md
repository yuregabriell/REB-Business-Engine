# Security and responsible automation

- No agent can claim external task completion without an observable tool result.
- External spending, contracts, publishing, emailing, direct prospect outreach and hiring require explicit user authorization, even for experienced operators.
- Financial projections are labelled scenarios, never promises. Source URLs require review.
- No bank passwords, private keys or production secrets in prompts, commits or journal.
- `REB_MODEL_*` optionally transmits the full project export to the user-selected API. Use only with permission to share those data.
- MCP stdio is a **local** tool server; do not expose it as a public TCP endpoint. Build a separate authenticated gateway if needed.
- Third-party skill files are untrusted; discover names only until approved, no auto-execution.
- Observe privacy law, marketing consent, ToS and rate limits for external research.
- `investment_gate` only returns a **recommendation**. It does not control purchases made through unrelated apps.
- For real businesses, take qualified legal, accounting and regulatory advice when required.
