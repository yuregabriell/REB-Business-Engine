# REB — Reverse Engineering Business

**REB is an evidence-led business operating toolkit**, designed for beginners and experienced operators. It coordinates 14 specialist roles, keeps an audit-friendly project record, calculates unit economics, tracks real experiments and learning, and exposes these tools through an MCP stdio server.

> **Status: 0.3.0 — functional development foundation, NOT a finished autonomous business agent.** The current version is local-first. Optional LLM and web-search APIs require operator configuration. A generic local MCP stdio client now executes **operator-allowlisted** tools; actual REA/RES integration is not yet configured or proven. Never treat an autogenerated hypothesis as a verified fact or any strategy as a promise of commercial success.

## Quick start

Requires Python 3.11+.

```bash
python -m pip install -e .
reb doctor
reb agents
reb init "Lavandaria à porta" "Recolha e entrega de roupa" --market Portugal --budget 300
reb projects
```

Use the `id` from `reb init` as `PROJECT_ID` in the commands below:

```bash
reb diagnose PROJECT_ID
reb suggest-experiment PROJECT_ID
reb evidence PROJECT_ID "Existe uma página de preços concorrente" --status verified --url "https://example.com/prices"
reb experiment PROJECT_ID "Clientes locais pagam pela recolha" --metric "pré-vendas" --target "3 pagamentos" --cap 25
reb finance --price 25 --variable 12 --fixed 200 --units 30 --cac 3
reb gate PROJECT_ID 50
reb journal PROJECT_ID "Primeiro contacto com um cliente" --kind activity
reb learn PROJECT_ID finance 1 "Explicou a diferença entre receita e lucro"
reb progress PROJECT_ID
reb export PROJECT_ID > reb-project.json
reb studio  # painel web local: http://127.0.0.1:8765
```

Values after `--price`, `--fixed`, etc. are *premises*, not predictions. The default currency label is EUR; no VAT or taxes are included.

## MCP — connect your AI host

The server exposes 21 tools to a compatible MCP stdio client:

```bash
reb-mcp
# or
reb mcp
```

Example MCP host configuration (replace Python executable with the absolute one if needed):

```json
{
  "mcpServers": {
    "reb": {
      "command": "reb-mcp",
      "env": {"REB_DB_PATH": "/absolute/path/to/reb-projects.sqlite3"}
    }
  }
}
```

Consult the documentation of your chosen host for its current configuration syntax. The ChatGPT remote plugin requires an **authenticated remote HTTP MCP server**; this stdio MCP server does not alone enable `@REB` in ChatGPT.

## Skills

Every specialist has an independent `skills/reb-*/SKILL.md`, along with the coordinating `skills/reb-core/SKILL.md`. These are designed to be readable by Agent Skills-aware hosts. They are not hosted agents by themselves; the host model supplies reasoning. If installing globally, copy the relevant skill directory to your host's skills directory as per its documentation.

## Optional model connection

An OpenAI-compatible `/chat/completions` endpoint can power any specialist role. This is a user-configured external network action; the default engine is deterministic and offline.

```bash
export REB_MODEL_BASE_URL="https://your-provider.example/v1"
export REB_MODEL_API_KEY="YOUR_API_KEY"
export REB_MODEL="YOUR_MODEL_NAME"
reb ask PROJECT_ID market "Como validar a procura por este serviço?"
reb mission PROJECT_ID "Encontrar o próximo teste de clientes" --max-agents 4
```

All supplied project information is transmitted to the configured model for an `ask` call. **Do not use third-party APIs with sensitive business data unless you are authorized to share it.** The generated analysis is labelled as a draft, not a verified result.

To discover potential public sources using optional Tavily API integration:

```bash
export TAVILY_API_KEY="YOUR_API_KEY"
reb research "lavandaria recolha entrega Lisboa concorrentes"
```

Search snippets are marked **unverified**. Inspect the original sources before recording a claim as verified. REB does not scrape paywalled or restricted websites and does not bypass access restrictions.

## Nexus, REA and RES

```bash
reb nexus --skills-root ./skills
reb delegate rea "Investigar UX de uma aplicação que podemos analisar legalmente"
```

`delegate` **prepares** a task. In v0.2.0, a separate `nexus-call` command actually executes a tool on a configured and trusted **stdio MCP server** with explicit tool allowlists and approval flags. Do not mistake this for a tested REA or RES integration: real external providers must be installed, their precise commands verified, and their schemas tested. See `docs/NEXUS.md`.

```bash
reb nexus-tools local-test --config examples/nexus-config.example.json
reb nexus-call local-test reb_list_projects --config examples/nexus-config.example.json --args '{}' --approve-external
```

The `rea` entry is only a placeholder, **not an executable command**, until explicitly configured.

## Added in 0.2.0 — methods, blueprints and source discovery

```bash
reb methods "validation"
reb blueprint PROJECT_ID --goal "Conseguir os primeiros clientes"
# Optional Tavily API key: discovery records are saved as UNVERIFIED, not certified facts
reb research-project PROJECT_ID "concorrentes de serviços de limpeza Lisboa"
```

Six original method cards contain attribution, evidence class, limitations, procedure and measurement. The local Studio now shows a blueprint and method library, and the stdio MCP exposes these operations to compatible AI hosts. External MCP calls can be added to the project as non-sensitive delegation receipts using `--project-id`.

## Architecture

- **Core:** 14 role catalog, stage-sensitive dispatch, guarded decisions.
- **Memory:** SQLite evidence, project, experiment, decision journal and demonstrated learning.
- **Financial calculations:** decimal-safe contribution, break-even and investment gate.
- **Evolution:** per-domain demonstrated skills, never arbitrary experience points.
- **Knowledge:** documented principles, evidence hierarchy, founder case studies.
- **Nexus:** capability discovery, preparation, **opt-in execution** of allowlisted external stdio MCP tools, non-sensitive execution receipts.
- **MCP:** newline-delimited JSON-RPC stdio interface with 18 tools.
- **Tests and CI:** pytest and GitHub Actions matrix.

See `docs/REB_DOCUMENTO_MESTRE_v1.0.md`, `docs/ARCHITECTURE.md`, `docs/NEXUS.md`, `docs/STATUS.md` and `docs/SECURITY.md`.

## Non-goals and safety

REB cannot promise revenue, conclusively determine demand from website visits, secretly discover private company financials, replace licensed professionals, automatically initiate purchases, or send messages without authorization. Copy business ideas ethically, not protected software, branding or proprietary content. Evidence is treated as untrusted data rather than executable instructions.

## Install specialist skills

Run from the cloned or extracted repository (no internet required):

```bash
python scripts/install_skills.py --host codex --dry-run
python scripts/install_skills.py --host codex
# or --host claude / cursor / project
```

Existing skill directories are preserved unless `--force` is passed. Do not install untrusted skills without reviewing their instructions. To publish with your own authenticated GitHub CLI, from the repository folder run `bash scripts/publish-github.sh YOUR_OWNER private` (the target repo must not already exist).

## Local REB Studio

```bash
reb studio --port 8765
```

Open http://127.0.0.1:8765 locally. The server binds only to loopback and is not a hosted website, nor safe to proxy publicly without separately implementing authentication, HTTPS and tenant isolation. This is a local human interface for projects and deterministic tools; external research and specialist model calls are currently available through CLI/MCP. Blueprint and methods are available through the Studio UI.
